# BMW M Showroom

Независимый виртуальный автосалон BMW M. Полноэкранный ролик, каталог с WebGL, вращением и окраской кузова. Доставка и самовывоз используют ту же выбранную модель и цвет в анимации.

## Запуск

Требуется Node.js 22+.

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

## Render

Тип сервиса — Static Site, ветка `main`, команда сборки `npm ci && npm run build`, каталог публикации `dist`. Также можно использовать `render.yaml`. Секреты, база данных и платная инфраструктура не требуются.

Сценарий оформления демонстрационный. Цены условные, данные заказа не сохраняются и не отправляются, платежный провайдер не подключен. Источники и лицензии опубликованы на странице /credits.html. Каталог открывается отдельно по /catalog/. У всех моделей есть студийный вид. BMW M4 и M3 используют локальные GLB, в общем зале можно выбрать соседний автомобиль, открыть водительскую дверь и осмотреть салон. У M5 сохранён авторский студийный кадр и ссылка на исходную модель. В общем зале M5 показана на стенде. Доставка полноэкранная, с демонстрационными полями и выездом автовоза. Анимация погрузки автомобиля доступна для M4 и M3.
